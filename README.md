# Simple Quiz Application

## Task 04 - Java Internship

A simple Java-based Quiz Application developed as part of my Java internship.

## Features

- Multiple-choice questions
- Four options for each question
- Instant correct/wrong answer feedback
- Score calculation
- Final result display
- Uses ArrayList to store questions

## Technologies Used

- Java
- Classes and Objects
- Constructor
- Methods
- ArrayList
- Scanner
- For Loop
- If-Else

## Sample Test

- Total Questions: 5
- Correct Answers: 5
- Wrong Answers: 0
- Final Score: 5/5

## How to Run

Compile:

javac Main.java

Run:

java Main
